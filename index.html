Kuafory

Multi-sector booking and business management platform

2025 – 2026LivePersonal product: design, development and deployment end to end

Layered, multi-tenant SaaS on ASP.NET Core / ABP Framework 10. One codebase serves eight sectors: hair salons, physiotherapy, dentistry, psychology, veterinary, dietetics, nail art and laser hair removal. Sector differences are handled with feature flags and a terminology dictionary; the code is not forked.

Highlights

  • The identity service runs as a separate application. The two services communicate over HTTP and RabbitMQ, and their data is separated at schema level.
  • Reliable messaging with the outbox/inbox pattern: events are written in the same transaction as the business record, and idempotent consumers prevent duplicate processing.
  • Permission-based authorization and resource ownership checks; consent flows for KVKK (the Turkish data protection law, similar to the GDPR) and health data.
  • Shared infrastructure extracted into 7 reusable NuGet packages: manager/repository bases, messaging, multi-tenancy, authorization.
  • Deployed on my own server with Docker Compose: nginx, Let's Encrypt, PostgreSQL, Redis, RabbitMQ. More than 1,600 unit tests.

NuGet packages

ERN packages

While building Kuafory, I moved the shared infrastructure into reusable NuGet packages. Both services use them in production.

  • ERN.CoreExtensionsBase classes for repositories and domain managers, plus a database schema check.
  • ERN.MessagingOutbox, inbox and idempotent consumers on top of RabbitMQ.
  • ERN.TenancyTenant scope and claims, resolved by three middleware components.
  • ERN.AuthorizationResource ownership checks on top of permission-based authorization.
  • ERN.AuthenticationToken validation for services that trust ERN.Identity.
  • ERN.Identity.ContractsShared event contracts between services, such as TenantChangedEto.
  • ERN.ConversationsIn-app messaging with file attachments.
